# Port Scanner
A simple Python port scanner built with sockets by Abel Mwedihanga.

## How to use
python Scanner.py <target> --start 1 --end 100

Example:
python Scanner.py 127.0.0.1 --start 1 --end 100
python Scanner.py scanme.nmap.org --start 20 --end 100

## What I learned
- Socket programming, threading, argparse
- How open ports can be a security risk
